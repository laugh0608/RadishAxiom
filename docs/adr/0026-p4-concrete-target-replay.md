# ADR 0026：P4 具体输入与精确目标重放

日期：2026-10-12。状态：Accepted，项目所有者于 2026-10-12 接受精确范围并要求实施 P4-B。

## 背景

[ADR 0025](0025-p4-request-response-model-decoding.md)的 P4-A 已实现请求规划、响应解析及确定性世界候选。候选不保证 Pre 成立或所选目标违反，不能直接进入反例结果。下一切片应直接解释原 IR，补齐这项实际缺口。

AX-B01 原容量 query 受 1 MiB stdin 上限阻断。这个阻断限制真实 solver 尝试，但不阻止用有限合成输入验收具体重放；尺寸与资源的改变须单独决定，不能混入本切片。

## 决定

1. 在现有 IR crate 交付 `replay_target`、`check_target_replay` 纯入口，显式选择 `axiom-p4-map-filter-replay-v0.1`。绑定真实 IR v0.2、完整 ir-derived P2、目标 ID、重放器源码身份、输入世界及显式预算，不使用候选名称或预设结果。
2. 覆盖现有 P3-A–D 的五类目标、input / filter / map 及同一 26 个表达式操作。整图扫描拒绝未支持功能，不因目标局部或死分支放行 join / group / 聚合。沿用原 P1 / P2 和已接受目标语义，不改变支持集合的原身份。
3. 直接读取 P4-A 的有类型 world 表示，重新核验完整接口、类型、容量、键及全部 assume。外键在 IR v0.2 由 assume 中的 lookup / match_option 表达，不增加隐藏模式或第二套外键声明。
4. 同时支持直接提供的规范 world 与绑定的 P4-A 模型候选。直接 world 不声称来自 solver；模型候选须核对 request / response / candidate 和原 IR / P2 / target 的绑定。两条路径都重新检查 WF / Pre，不依赖请求尺寸门禁取得语义答案。
5. 用数学整数 / Fixed 系数、精确 Text 和有界平坦值 / 显式工作栈解释原 IR；不用 SMT 编码器、SMT 解释器或模型的派生输出值自证。可以复用 P1 类型与图对象，依赖必须明确，本仓重放器不等于跨仓独立 checker。
6. 分别返回输入拒绝、Pre 拒绝、当前世界目标违反或当前世界目标未违反的版本化内部观察；程序的其他故障不替代所选目标。范围、总定义性、键 / 基数、覆盖和 guarantee 分别遵守原 Reach / Ready / ProgramOK 条件。
7. 合成验收复用现有 Python 有限具体解释并增加手算区分例、绑定与制品篡改、资源及深度检查。合法 map / filter 的重复键 / 覆盖负例通过仅测试可见的关系材料验收，明确局部注入与完整程序的区别。

精确入口、字节、求值、诊断、预算与验收见[规则](../query/p4-concrete-target-replay-v0.1.md)。

## 影响与接受范围

新增内部重放器与版本化有限观察，不改语义快照、IR / P2 / query / P4-A 原规范、Evidence、registry、execution profile 或锁定材料。自有有界十进制加减使用现有依赖，不安装或升级依赖。

接受本决定只授权 P4-B 实施和合成 / 本机组件验收。它不授权真实 solver 校准 / 执行、增限、新 query profile、完整 Evidence v0.2、独立 checker、跨仓、P7 / P9、后台服务、系统或远程变更、发布与正式实验。提交和 push 仍按用户当前任务的明确要求分别处理。

## 验收与停止线

必须展示 AX-B01 原容量三个候选在同一有限输入上得到不同实际 guarantee 观察，并保留 wrong-drop-zero 忠实执行错误谓词时内建 coverage 成立。覆盖 WF / Pre 无效、Pre 故障、其他目标故障但所选目标成立、上下游故障、严格兄弟与未选分支、零实例、目标容量前完整行和全部键分量。

只有 WF / Pre 成立且精确目标违反才返回目标违反观察；预算不足、未支持功能、绑定或格式错误没有部分成功制品。当前世界未违反不能升级为普遍证明，有限重放不能认证 solver 来源或取代独立检查。AX-B01 的 stdin 拒绝不随本决定解除。
