# ADR 0024：字段来源与保守标签结构推导

日期：2026-10-08。状态：Accepted，项目所有者接受 P3-F 范围并要求继续实施。

## 决定

按[字段来源与 P4 接口审阅](../query/field-origin-and-p4-interface-review.md)，在现有 IR crate 内交付 `derive_field_origin` / `check_field_origin`，覆盖全部五种 P1 v0.2 节点及合法逐行表达式、复合字段。输入为不可变完整 IR / P2、原 field-origin 目标、显式生成器身份和预算。

从实际 IR 重建来源、声明 / 推导 / 传播标签、行控制与求值上下文，导出带角色前提边的版本化 DAG。共享图不展开为所有路径或容量世界；输出仅保留目标三类根的引用闭包。完整记录可含静态标签缺口；生产 strict 和独立 Python 有限核对检验记录正确性，不删除缺口或伪造具体反例。精确规则见[字段来源推导 v0.1](../query/core-field-origin-v0.1.md)。

## 边界

完整 P1 类型、结构与身份仍是输入前提。保守分析沿用现有 P1 规则，不提高分析精度、不新增任务白名单、不改变 P1 接受集合或原 P2 命题 / ID。业务等式、运行故障与双世界非干扰分别由相关义务处理；求值上下文只描述静态语法，不声明无故障或所有分支都动态执行。

新记录是内部分析制品，无 Evidence 五态、公共 prove / kernel / certificate support 或执行许可。无缺口不等于原义务已有公共证明，有缺口不等于存在泄漏反例。接入完整 Evidence 前仍须审阅充分条件与未覆盖边界，改变原命题必须新版本。旧 IR / P2 / query / effect / Evidence 字节保持。

本决定只接受 P3-F；P4-A / P4-B、依赖、服务、solver、跨仓 checker、远程操作和正式实验不在范围内。
