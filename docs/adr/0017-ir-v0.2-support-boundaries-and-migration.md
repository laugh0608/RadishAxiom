# ADR 0017：IR v0.2 支持边界与显式迁移

日期：2026-10-05

状态：Accepted

用途：闭合 P1 实施发现的四项公共格式 / 拒绝边界，并定义与 v0.1 并存的版本化推进范围。

不包含：新的首域、算术或效果能力、Evidence v0.2 接受、P2–P9 实施、公开 CLI / 发布、跨仓写入或外部工具执行。

## 背景与接受

[P1 支持边界审阅](../ir/p1-support-boundary-review.md)确认：record.fields 元素缺少精确成员；is_some 被说明引用但未列入机器 tag；记录相等与连接字段对适用集合未闭合；主键投影没有区分直接读取与可证明同值的复杂表达式。内部组件以 Unsupported 保留缺口，不能据四题通过宣称完整 P1。

2026-10-05，项目所有者在审阅四项边界、公共格式及迁移影响后明确回复“接受，继续推进下一步”，接受本 ADR 所述窄范围。本决定依据 ADR 0003 的独立版本原则和 IR v0.1 minor 升级要求；不修改旧 ADR、语义、IR 或 Evidence 的绑定字节。ADR 0016 的 P1 输入范围扩展为精确列举的 v0.1 与 v0.2，其他阶段与执行门禁不变。

## 决策

1. [IR v0.2](../ir/axiom-ir-v0.2.md)与其[语义快照](../semantics/keyed-finite-table-semantics-v0.2.md)单独保存。旧版本继续按原规则读取，不透传新成员、混用语义摘要或猜测旧版缺失形式。
2. record.fields 每项精确为 name / expression，完整、唯一、同型、按 Unicode scalar 名称序规范化；所有字段共享外层绑定环境，全部检查。构造和字段读取保留声明标签与实际依赖，不允许公开声明抹去敏感来源。
3. is_some 只作描述性简写，机器 IR 使用现有 match_option 的 false / true 分支；拒绝 is_some tag，不引入 alias 或规范器自动展开。
4. 通用 eq 与 join pairs 只接受完全同型的标量及递归 Option，排除记录与任意 Option 包装记录。记录需按字段显式比较，不新增隐式结构相等。
5. map / join 输出键必须直接读取源行 / 左行键，并与所有源键形成双射；复杂同值表达式也拒绝，不引入求解器或单射性证明。非键字段仍可按现有表达式派生。
6. 六类内容身份使用 `axiom-ir-v0.2:*` 域，新文档绑定新语义摘要。由新域引起的所有 ID 与引用必须完整重算，绝不只改版本字符串或替换顶层摘要。
7. [显式迁移规则](../ir/ir-v0.1-to-v0.2-migration.md)先严格验证源、重绑依赖与身份、再次执行目标规范化和检查，返回两端身份及工具 / 规则版本。不得猜测源版 Unsupported，也不复用证明、检查结果、缓存或运行许可。

## 兼容性与责任

v0.1 可验证且落在共同支持集合内的 IR 可以迁移。它的输入 / 输出名称、数学值、契约角色、绑定索引、枚举与主键顺序、效果和程序行为保持不变；域与语义摘要变化使字节与身份改变。不能无损映射的材料拒绝，不用默认值或求解器补全。

IR 读取支持升级不等于 Evidence、pipeline 或 checker 支持升级。Evidence v0.1、28 个 bundle、runtime 与 payload 登记、实验注册及其摘要保持原样；它们不接受新 IR 身份。P2 仍按 ADR 0009 闭合义务 profile，旧 Evidence 状态不得跨版本复制。独立 checker 的格式导入和动态对照需要另行跨仓交接；本仓交付规范、独立期望、正负例与精确摘要。

## 验收与停止条件

- 四题 12 个旧候选严格源检查后迁移，对照 Python 独立目标字节、六类身份与完整文档摘要；错误算法继续保持结构合法。
- 新记录构造含同域名称、嵌套记录 / Option、绑定、字段规范化及标签正例；缺失、重复、错型、未知成员、旧拼写、隐藏坏分支与预算失败均拒绝。
- 相等、连接、直接键、is_some 拒绝按版本分别验证；v0.1 继续保持原 Unsupported，不用新规则倒改旧语义。
- 版本 / 语义混搭、遗漏重绑、旧摘要域、非法源、非规范源与错误源版本不得形成迁移成功；输出目标必须能 strict 重验。
- 迁移不能任意替换与摘要同拼写的名称或文本字面量；只重写规范中的引用位置，且在引用改变后重新排序表达式。

组件回归与独立生成期望不等于真实 checker、六平台、公式证明或全管线验收。发现新语义歧义时只停止相应部分，报告具体缺口；本决定不扩展为未列出的语言能力。
