## 开发期失败与修正

未以重跑成功抹掉以下实际失败：

1. 首轮 25 项阶段测试有三项失败：生产允许表遗漏原配方的 `PKG_CONFIG_SYSROOT_DIR`；JSON 深度未显式限制。补齐原配方键并加入 64 层预算。随后发现本机 Python 自动增加 Darwin 专用键，合成测试只在调用入口前移除该宿主键；Linux 允许表未为此放宽。
2. 新增的累计计数回退、未登记命名空间别名、隐式脚本隐藏未知输入三条回归先实际失败，再补上拒绝。诊断先后顺序变化造成的一次预期消息不匹配也已修正。
3. 独立树检查首次报 `old-review-tree-drift`；逐文件比较确认字节与执行位未变，原因是复核脚本使用 Path 分量排序，而既有规范按完整相对路径字符串排序。修正独立规范化顺序后通过，没有改旧树或旧记录。
4. 真实包样本检查曾把固定 AArch64 `libm.a` 预设为 linker script，解析器正确拒绝二进制内容；读回确认其为普通 GNU archive 后，修正测试的已知样本类别，没有增加 fallback。

初始候选与其失败状态保留在上述任务目录；后续代码变更会使它的引用漂移，不能把它作为最终接受材料。最终验证另命名保存，没有覆盖原候选。
