# 本地 cvc5 构建来源：阶段边界与验收审阅

日期：2026-10-27。状态：**随 ADR 0031 D1–D3 接受的验收要求；有限离线组件已实现，真实适配与资格未完成**。用途：承载受控阶段、稳定链接输入与 A1–A10 的具体验收条件，供实施者和独立复核者使用。适用范围、保证减少、信任及迁移决定仅由 [ADR 0031](../adr/0031-local-cvc5-build-provenance-boundary.md)定义；本专题不另建来源账本或公共格式，不提供执行授权，不接受任何工具或宿主。

项目所有者已于 2026-10-27 接受 ADR 0031 D1–D3，本文仅在其限定范围内接续[C2 接线要求](solver-cvc5-execution-preparation.md)。[私有 v0.2 离线入口](solver-local-cvc5-offline-v0.2.md)须显式选择；默认 v0.1、旧冻结配方字节及其拒绝保留。以下验收没有因范围接受或离线组件通过而整体通过，不能把文档、合成矩阵或字段形状通过写成实际资格。

## 受控阶段的最小关系

- 启动前绑定精确宿主 / 内核 / runtime、工具与 SDK 根、完整 argv / cwd / 环境、挂载、身份、FD 和资源策略。文件输入之外的时间、随机性、CPU / 内核返回值及允许的伪文件单独列入环境 / 信任范围；不声称记录了所有返回值，也不承诺输出确定。未定义的宿主能力通道必须先阻断或审阅。
- SDK、原源码与配方只读；构建所需源码副本从绑定原树产生并记录变换。每批工作根独占新建、无历史缓存；网络、宿主 socket / credentials、共享目录和额外继承 FD 不可用。只读容器视图不足以排除宿主可写别名；必须审阅所有可写入口及外部写入防护，不能用事后同名路径摘要代替对象固定。
- 阶段边界复用原配方命令和 review-gate，先明确需要保存的输出与消费者。阶段结束后确认该阶段全部构建后代已退出、必要流关闭、无仍能写入的进程 / 映射，再由受保护控制面采集输出、检查额外文件与变换、冻结供下一阶段消费的根。其余可写区域不得成为下一阶段未登记输入；完整工作树或批准子集均须显式绑定，不能携带未登记残留。
- 生成文件记录生产阶段及其整组输入 / 命令 / 输出摘要，阶段内并发工具由精确构建工具信任承担，不虚构完整内部读取历史。配置头、目标对象、archive 和响应文件等规定材料必须留存。原构建需修改的文件须在相应可写阶段声明，不通过临时放开冻结根完成。
- **链接消费边界必须稳定。** 最终链接的对象、archive、脚本与响应文件须在消费前完成冻结，或提交可审阅且可验证的等效不可变对象方案；链接输出使用独立可写位置。拆分构建步骤不得改变既定 flags / 顺序 / 功能面。若当前构建无法提供这些材料和边界，C2 不通过；不以链接后同名文件的摘要追认实际输入。
- 构建进程不能改写控制面记录、接受结论或已冻结输入。控制面独立记录启动 / 退出、限制读回、输出捕获和阶段封闭事实；工具日志保留为单独来源。首错保留，禁止将构建过程自行打印的 success 转成资格。

这要求阶段与最终链接的具体拆分在实施前核实；本文没有证明既有 CMake / Make 配方已经满足它，也不要求记录自然消失且未列为必要留存材料的全部临时版本。

## 必需验收矩阵

下表是未来验收要求，**当前全部未因本文而通过**。离线规则测试和真实资格分开报告；独立期望不得由同一生产 helper 生成。

| 项目 | 正向证据 | 必需负例 / 拒绝 |
| --- | --- | --- |
| A1 范围与版本（离线） | 规则 / 配方 / 输入根 / 阶段 / 产物身份一致，新私有版本可严格重建 | 缺少范围、混用旧接受记录、新摘要冒充旧 CLI、未知字段 / 重复 JSON 键或定义 ID、关系循环 |
| A2 输入接受（离线审阅） | C1、工具 / SDK、许可、patch 与组装差异分别接受，原字节核对 | LibPoly 仍未闭合、额外文件、错误包 / 模式 / 链接、未审扩展属性；拥有摘要不替代接受 |
| A3 输入封闭（真实资格） | 精确隔离实例内只可取得批准文件与声明环境输入 | 已知存在的宿主哨兵文件、网络端点、socket、共享缓存和额外继承 FD 不可访问；不能仅以路径不存在通过负例 |
| A4 稳定性与阶段封闭（真实资格） | 冻结根防写、无可写别名、完整后代收束，下一阶段消费相同对象 | 宿主并发替换、链接逃逸、继承写 FD / 映射、延迟子进程、未登记工作区残留；后验 hash 相同不代替防护 |
| A5 生成关系（离线加真实捕获） | 合成及真实生成头 / 对象均能沿绑定阶段回溯；规定输出完整 | 伪造生产阶段、修改已冻结生成头、集合外或无所属阶段的临时输入、丢失必需对象、把阶段来源伪装成逐次读取证明 |
| A6 链接组成（独立字节核对） | 有序命令、响应文件、对象 / archive 成员、map / trace 与 ELF 对应；保序及必要库重复、strip 前后分别绑定 | 错对象 / ABI、额外库、成员遗漏或重名歧义、错序 / 静默去重、响应文件截断、消费后替换、未知启动对象、异常动态依赖 |
| A7 捕获与信任（离线加真实资格） | 受保护的外围记录与工具观察分开；篡改可被拒绝 | 构建进程修改 receipt / success、截断日志、伪造退出、遗漏 trusted 控制面、把使用观察标为完整集合 |
| A8 资源与终止（真实资格） | 原构建额度、核定 PID / inode、观察间隔、留证预留、外层整树终止均实际验收 | 越额、失联、取消、超时、daemon 不响应及未知残留；不允许仅杀父进程后继续 |
| A9 实际新候选与 E0（独立审阅） | 真实依赖与主目标构建材料、有效配置 / ELF / 全部组成 / 许可核对通过，项目所有者接受精确本地范围 | 只有合成事件 / 手写 manifest、未闭合来源、功能 / 配置漂移、把构建完成当成 E4 或运行许可 |
| A10 兼容与失败保留（离线） | 旧入口 / profile / 字节与拒绝保持，失败不生成可接受的部分制品 | 自动降级到旧规则、自动补材料 / 重试 / 增限、覆盖旧失败、将 unknown 改成功 |

不以“没有完整逐次读取日志”拒绝新方案；但 A3 / A4 未通过时，也不能因为删除了读取门禁而接受。允许集合中的文件未出现在使用观察中，不足以认定其被使用或未使用。发现观察引用集合外对象或未知生成来源时必须失败；未发现矛盾不构成抵抗受信任工具伪造的证明。

## 验收交接与执行前阻断

每项实际验证须绑定规则版本、原输入 / 生成入口、预期、工具 / 环境、原始结果和未覆盖范围。A1–A10 各自报告未运行、失败或实际通过，不能合计成一次不存在的全量验收。复核材料缺失时保留缺失；独立来源检查不与独立程序语义 checker 混称。

实施前仍须给出能够保持原 flags / 链接顺序的阶段拆分，明确如何阻断宿主可写别名、隔离外围记录、处理工作区残留并确认后代退出。阶段方案已完成静态核定，真实适配、输出和 OS 资格仍未取得。不能先生成虚构接受记录，再以本矩阵充当其依据。

范围接受只允许按后续具体授权推进有限实施；C1、实际构建环境资格、每批组装 / 构建授权、C4 / E0、E4 / E5 分别成立。停止、维护成本与重评按 ADR 0031 的 D3 执行；不另设放宽规则。

阶段拆分的静态核定与下一批职责 / 成本见[有限实施计划](solver-local-cvc5-phase-plan.md)。其中离线切片已按授权完成，见[本批记录](../records/2026-10-27-cvc5-offline-phases.md)；真实适配与 A1–A10 的实际资格仍未取得。
