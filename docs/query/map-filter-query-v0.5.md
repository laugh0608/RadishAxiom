# map / filter query v0.5：确定性紧凑表示

日期：2026-10-17。状态：Accepted，依据 [ADR 0027](../adr/0027-compact-query-and-p4-binding.md)。

用途：规定同一类型化公式的规范化、字节、身份和生产资源边界，供编码器实现者及验收者使用。

不包含：新的语义义务、真实 solver、关系编码替换、等价性证书、公共 Evidence 或独立 checker 支持。

## 身份与支持集合

profile 为 `axiom-p3-map-filter-query-v0.5`，artifact 为 `axiom-smtlib2-qf-uflia-query0.3`，方言为 `SMT-LIB-2.6/QF_UFLIA`。绑定保留原 IR raw / document、完整 P2 raw、精确目标、语义、生成器源码身份，并新增 `query_rules`，值为本文件完整 UTF-8 字节的 raw SHA-256。摘要格式沿用 `sha256:` 加 64 位小写 hex，不内嵌自身摘要。

五类目标与整图支持集合完全继承 [v0.4](map-filter-query-v0.4.md)及其引用的 [v0.3](map-filter-query-v0.3.md)、[v0.2](map-filter-query-v0.2.md)、[v0.1](map-filter-query-v0.1.md)。输入仍为 IR v0.2、完整 ir-derived P2、精确目标与显式 GeneratorIdentity。NotProve、UnsupportedKind、整图 UnsupportedFeature、版本与绑定拒绝保持；先完整检查，再进行表示变换，不通过裁剪隐藏不支持的节点或契约。

只改变表示，不改变 WF、Pre、各类 violation、Ready、严格求值故障或原容量。化简作用于已经编码的全定义 SMT Bool / 数学 Int / Text 项，不是对 IR 求值过程的短路优化；不能加入“输入合法”“其他义务成立”或“活动槽位连续”等假设。

## 原 DAG 与规范化顺序

先按照 v0.4 对同一目标的构造顺序建立类型化原 DAG，包括固定 false / true、全部自由符号、最终不可达项和原故障条件。其 SmtNodes 等原构造费用仍完整累计。所有引用必须指向较早项且 sort 合法；最终根必须为 Bool。不生成旧 SMT 文本作为中间输入。

按原 term 序从小到大转换。每个原项映射到一个规范项；先转换有序前提，再按下表应用规则。规范项 ID 按首次实际插入递增，常量包括 sort / 精确值，自由符号包括 sort / 原 term 身份，应用包括 sort / op / 有序前提。相同键取首次代表；不能合并不同自由符号，也不能把不同自由 Text 当成不同常量。新生成的常量或 `not` 按同一插入与共享规则处理。返回前提的规则不额外创建节点。

下表每行按列出的先后判定；命中返回规则立即结束该项处理，未命中则共享该应用。除表中明确排序外不交换、展平或重新结合操作数；不做固定点扫描，不根据可满足性化简。

| 运算 | 按顺序应用的精确规则 |
| --- | --- |
| `not a` | Bool 常量取反；若 a 为 `not b` 则返回 b；否则保留 |
| `and` / `or` | 有吸收常量则返回 false / true；否则删除单位常量 true / false，并按首次出现去重规范项 ID；空列表返回单位常量，单项直接返回，其余保序保留 |
| `= a b` | 同 ID 返回 true；两边都是同 sort 的 Bool / Int 常量时精确比较；否则将两个规范 ID 按数值升序放置。Text literal 仍是自由符号，互异条件仍在 WF 中 |
| `+ a b` / `- a b` | 两个 Int 常量作数学加 / 减；否则右边为零返回 a；加法左边为零返回 b；减法同 ID 返回零；否则保留 |
| `<` / `<=` / `>` / `>=` | 同 ID 分别返回 false / true / false / true；两个 Int 常量精确比较；否则保留 |
| `ite c a b` | c 为 Bool 常量时取相应分支；a / b 同 ID 时取该项；若结果为 Bool 且 a=true、b=false 则取 c，a=false、b=true 则按上述规则生成 `not c`；否则保留 |

数学整数不得截断、溢出回绕或转为浮点。超出显式整数字数预算时拒绝，不改为“保留未折叠公式”后沿用同一 profile。实现使用既有数学整数能力或受限十进制运算，不因本稿接受自动授权依赖安装。

## 可达性、名称与规范字节

从最终根迭代遍历规范 DAG，只输出根可达的派生项；全部自由声明仍输出，包括不可达项、inactive 槽位载荷、None 内叶及全部 Text literals。完整符号映射从原 IR origin 产生，不接受调用方自定义映射。

令 N 为自由符号数量，按 v0.4 完整自由名称的 ASCII 字典序排名 r，名称为 `s` 加宽度 `max(1, digits(max(0,N-1)))` 的十进制 r，左侧补零。排名依据完整旧名称，不能改为原 term 的数值顺序。原名称只需从 term 身份计算，不要求创建旧文本制品。新名字严格保序且与原名字双射；每项 sort / origin 保持。AX-B01 的 501 个自由声明为 `s000` 至 `s500`。

输出为 ASCII / LF，首尾固定：

```text
(set-logic QF_UFLIA)
(declare-sort Text 0)
…全部 declare-const，按新自由名称升序…
…实际保留的 define-fun，按规范项 ID 升序…
(assert 根引用或根表达式)
(check-sat)
```

省略号是本稿说明，不进入字节。每条命令一行，唯一末尾 LF，无注释、额外空行、路径、时间或追加命令。声明为 `(declare-const sN Sort)\n`，保留定义为 `(define-fun dN () Sort Expr)\n`。`dN` 的 N 是实际保留定义的从零开始的连续序号，不补零，命名空间与自由声明分离。应用为括号包裹 op 和单空格分隔的参数；Bool 为 true / false，非负 Int 为规范十进制，负 Int 为 `(- magnitude)`，不存在负零。Text 不出现直接常量。

### 固定的有界代入

对根可达 DAG 统计直接引用次数 uses：根先计一次，每个可达应用的每条操作数边再计一次；重复边分别计数。此后不因内联父项而重新累计。

按规范项 ID 升序生成表达式。自由引用高度为 0；常量的策略高度为 0（包括负整数表示）；应用高度为 1 加子引用高度最大值。表达式字节 E 是已选定子引用构成的完整 ASCII 长度。设待保留名称为当前 `dN`，完整定义行长度为 D，名称长度为 L。满足以下任一项则代入，否则输出定义并把其引用高度重置为 0：

1. 常量 E ≤ 16；
2. uses = 1，E ≤ 128，策略高度 ≤ 8；
3. uses > 1，E ≤ 32，策略高度 ≤ 8，且 `uses × E < D + uses × L`。

等成本保留定义。固定参数不是调用方预算选项；策略高度不是 SMT parser 的括号深度预算。最终未内联定义体和 assert 可以比内联项高一层，负整数还含自己的语法括号；不得据此误用 8 作为通用解析深度。

长度和成本均先 checked 加乘，再分配 / 拷贝。局部成本判定不保证全图最优或每一步都缩小；后续父项代入可能复制子文本，仍受临时字节及最终输出预算约束。预算不足只能拒绝，不能改变内联选择。

## 生产预算与实际用量

所有预算显式提供、包含等号，零不是无限；加乘溢出为对应资源拒绝。保留原 QueryLimits 的 JsonLimits 与六项预算、QueryUsage 的六项含义：前五项计原构造，OutputBytes 计最终新 SMT。旧四版的旧接口和用量不塞入新零值成员；新 profile 使用类型化的 compact limits / usage，由既有编码与 strict 入口显式承载，不能隐式选择。

新 compact 预算闭合成员如下；除 maximum 类外，用量为累计量，不因释放而返还。临时工作费用与原 ValueCells 分开，不能用最终共享后大小抵消原费用。

| 成员 | 计数与检查时机 |
| --- | --- |
| `max_normalized_nodes` | 每个新规范项插入前计一；包括化简新常量 / not 和最终不可达代表，命中共享不重复计节点 |
| `max_normalized_edges` | 新规范应用插入前按参数数累计；重复操作数边分别计；共享查找临时参数仍计 scratch |
| `max_scratch_cells` | 新建 / 复制的原项映射、索引、规范化候选参数、查找表条目、可达 / uses / 名称 / 引用记录、工作栈及排序临时数组元素；每个元素一单位，重复 push / 复制重新累计，分配前计费 |
| `max_work_steps` | 每次项访问、边扫描、规则分支判定、表查找 / 比较、排序比较、长度计算项及渲染片段处理计一步；复合键 / 字符串 / 大整数的实际比较、散列、复制或运算按访问的项 / 字节另累计；内层循环及失败路径同样计费 |
| `max_temporary_bytes` | 新复制的常量十进制、名称、共享键字符串和表达式 / 引用缓冲字节累计；释放不返还；计算长度后、分配前收费。最终制品另计 OutputBytes，不重复作为 temporary |
| `max_integer_digits` | 单个原或化简所得 Int magnitude 的最大十进制位数，不含负号；中间加减工作缓冲也受 temporary / work 预算约束 |
| `max_dag_depth` | 原 DAG 与规范 DAG 的最大依赖深度，常量 / 自由项为 1，应用为 1 + 最大前提深度；与代入策略高度独立 |

scratch / work 是明确的逻辑资源计数，不是宿主分配字节；实现必须在代码与验收中展示逐类收费位置。查找、排序不能调用无法中止的无界回调；哈希碰撞处理也不能绕过工作预算。成功 query 保留新实际用量；预算值和实现策略可能影响用量或拒绝点，但所有足够预算必须得到相同字节。不得用随机容器遍历决定代表、名称或输出。

生产不提供研究脚本的宽松默认值，不把原型 64 MiB 输入预算变成生产 stdin。P3 最终输出仍受调用方显式 max_output_bytes，P4 额外强制完整 stdin ≤ 1,048,576；P3 允许做受限的大查询诊断，但不能据此放宽 P4。

失败保留资源名、目标及构造 / 规范化 / 渲染阶段，不返回部分成功 query、名称映射或默认 unknown。类型化平坦 DAG 与有界显式栈避免依赖恶意深递归；这些组件预算不是 OS 硬内存或时间保证。

## strict 与验收

`check_query` 从同一 IR / P2 / 目标 / generator 和显式 profile / 预算重建，逐字节核对，并核对完整绑定、规则摘要、全部 symbols / origin。调用方给的摘要、压缩文本或名称映射不能绕过重建。

- 旧四版的规范文件、固定材料、bytes / digest / symbols / 六项 usage 与拒绝回归保持；新旧 artifact / profile 不能混配。
- 新 profile 覆盖五类目标、所有既有有限语义材料与原容量 AX-B01 三候选。与同输入 v0.4 经研究原型所得 bytes 作表示回归，另由独立 IR / SMT 解释路径核对实际新字节；研究原型不是唯一正确性 oracle。
- 手算覆盖每种恒等规则及排序 / 共享 / 内联边界，包含 Text 自反但非不同符号互异、fault / Pre、None / inactive、双向 coverage 的负向变异、零容量、深链、高元数与超过 1 MiB 的合法输出。
- 每类资源取实际用量 U 验证 limit=U 成功、U−1 拒绝（U>0），另测零、checked 溢出与拒绝时不分配大对象；所有足够预算生成相同字节。重复生成和扰动不具语义的输入排列不得改变结果。
- 72 条旧 profile 记录仍作为兼容基线；新 v0.5 按三候选实际支持目标生成一次，各目标明确对应旧记录，不能把重复 profile 计作新增语义覆盖。重新报告原容量最大 stdin、余量和各项生产资源用量。

有限比较与逐项恒等式论证不是机器检查的等价性证书；本规范不产生 proved / checked 等 Evidence 状态。
