# Agent Representation Experiment v0.1

本目录保存首轮 Agent 表示与验证反馈对比实验的机器注册和未来执行锁。正式协议见 [Agent 表示与验证反馈对比实验预注册 v0.1](../../docs/experiments/agent-representation-preregistration-v0.md)。

当前只登记协议，不包含模型响应或实验成绩。`registration.json` 由 `registration.sha256` 绑定；在任何 AX-B01 至 AX-B04 模型调用前，还必须提交协议规定的 `execution-lock.json` 和全部提示材料摘要。

接受本目录不授权调用外部模型、安装 runner 依赖、启动服务或写入远程状态。
